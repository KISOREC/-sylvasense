# Geospatial modules

Ownership: Earth Engine setup and exports live in `earth_engine/` and `exports/`; source discovery/acquisition in `acquisition/`; raster preparation and indices in `preprocessing/` and `indices/`; change algorithms in `change_detection/`; vector products in `vectorization/`; and quality checks in `validation/`.

Preserve source identifiers, acquisition dates, CRS, resolution, and other relevant metadata. Distinguish real observations from clearly labeled synthetic test fixtures. No official forest boundary dataset is bundled.
